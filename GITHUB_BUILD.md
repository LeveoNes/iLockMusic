# Сборка APK через GitHub Actions

1. Создайте новый репозиторий GitHub, например `ilock-music`, и загрузите **содержимое папки `iLockMusic`**, не саму папку (файл `.github/workflows/build-apk.yml` должен оказаться в корне репозитория).
2. Откройте вкладку Actions и выберите Build Android APK.
3. Нажмите Run workflow и дождитесь успешной сборки.
4. Откройте завершённый запуск, скачайте артефакт `iLockMusic-debug-apk`, распакуйте ZIP и установите `app-debug.apk` на Android.
5. Запустите Яндекс Музыку и воспроизведение, откройте iLock Music и выдайте доступ к уведомлениям, если приложение запросит.

Это тестовая сборка, не проверенная на реальном устройстве. Не является полноценной заменой системного экрана блокировки.
